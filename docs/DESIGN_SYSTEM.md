# Vivi Design System

Status: planning

## Palette

- Primary Blue: `#2563EB`
- Dark Blue: `#1E3A8A`
- Navy: `#172554`
- Light Blue: `#DBEAFE`
- Very Light Blue: `#EFF6FF`
- White: `#FFFFFF`
- Background: `#F8FAFC`
- Primary Text: `#0F172A`
- Secondary Text: `#64748B`
- Borders: `#E2E8F0`

## Principles

Use white surfaces, restrained blue accents, accessible contrast, clear hierarchy, rounded cards, subtle shadows, and consistent interaction states.

## Initial tokens

Define reusable Tailwind tokens for color, typography, radius, spacing, and shadows before individual pages.

## Components

Button, input, textarea, select, card, dialog, toast, alert, badge, tabs, table, pagination, file dropzone, status indicator, and empty state.

## Breakpoints

Verify the final interface at mobile, tablet, laptop, and wide desktop widths using Playwright and responsive manual checks.
